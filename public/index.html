    Settings

    Focus

    Start a session from any task's 🍅 button — presets 25/5, 50/10 or Custom. Focus time is tracked per task and project; a task is never completed automatically unless the option above is on.

    Habits

    Off by default — habits are a separate module: task statistics stay pure unless you turn this on. Habit days never count as overdue.

    AI

    ✨ “Break this task down with AI” only ever suggests: you review, edit and check every step — nothing is created until you press “Add selected tasks”. No API keys live in the browser; an operator can wire a model on the server via ZT_AI_URL / ZT_AI_KEY / ZT_AI_MODEL.

    Notifications

    Permission is only requested when you click “Enable Notifications” — never on load. On phones, alerts are delivered as persistent notifications through a service worker; where unsupported they appear in-app. Snooze offers 5/10/30/60 minutes and Tomorrow.

    Your data is saved in this browser first (IndexedDB + backup mirror), and — when online — synced to the server so it survives cleared browser data and works on other devices. Exporting a backup JSON is still a great extra safety net.
